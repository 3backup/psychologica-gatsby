# Instrukcje projektu

Nie używaj znaku U+2014 w odpowiedziach ani przygotowywanych treściach. To stała preferencja użytkownika; stosuj kropki, przecinki, dwukropki lub nawiasy.

Przeczytaj i stosuj wszystkie instrukcje w [AGENTS.md](./AGENTS.md), w tym obowiązkową kontrolę GitHub, faktycznej wersji aplikacji i DatoCMS, porównanie lokalnego środowiska z produkcją, blokowanie ingerencji przy niepewności oraz osobną zgodę na destrukcyjne operacje i plan odzyskania.

Przy wdrożeniu obowiązuje [deployment/README.md](./deployment/README.md). Sam push ani zielony pipeline nie kończy wdrożenia. Potwierdź niezależnie GITHUB / APLIKACJA / BAZA i przekaż dowody kolejnemu agentowi. Każdy brak potwierdzenia oznacza NIEKOMPLETNE/ZABLOKOWANE. Same pliki instrukcji nie gwarantują przestrzegania zasad przez wszystkie narzędzia.
